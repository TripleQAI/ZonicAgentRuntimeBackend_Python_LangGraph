# ZonicAgentRuntimeBackend_Python_LangGraph

Backend of the Zonic Agent Runtime: builder workflows compiled at run time to LangGraph `StateGraph`s, persistence through the pgfoundation gateway, Langfuse traces in PostgreSQL. The runtime UI is deferred.
