# SP-2: `TurnSaver`, interrupts in nested graphs, new-process resume, conformance, `error_handler`

Scripts: `spikes/turnsaver.py`, `spikes/sp02_graphs.py`, `spikes/sp02_resume.py`, `spikes/test_sp02_turnsaver.py` (5 checks, all pass).

| Question | Result |
|---|---|
| Interrupt in a child graph invoked inside a node, `durability="exit"` | One checkpoint in the root namespace and one in `subflow:<task id>`. The bundle has 2 checkpoints, 2 writes and 7 blobs, 2,671 bytes as JSON. |
| Resume of that bundle in a new Python process | Completes: `pre`, `subflow`, `post`; the answer reaches the child; nothing on stderr |
| `HumanInTheLoopMiddleware` interrupt inside a `create_agent` graph invoked in a node | HITL request with `action_requests` and `review_configs`; bundle 3,898 bytes |
| Resume in a new process with `{"decisions": [{"type": "approve"}]}` | The tool runs and the final answer is produced. The model is called once in the new process; the first turn is not repeated. |
| `durability="async"` bundle, full versus latest-only | 5 checkpoints / 5,569 bytes versus 2 checkpoints / 2,737 bytes; the latest-only bundle resumes |
| Interrupt IDs | 32 hexadecimal characters; they cast to the `uuid` of `runtime_interrupt.interrupt_id` unchanged |
| Conformance suite (`langgraph-checkpoint-conformance` 0.0.2) | Every base capability passes: put 17, put_writes 10, get_tuple 10, list 16, delete_thread 5. The extended capabilities (`delete_for_runs`, `copy_thread`, `prune`) are not implemented and are not needed. |
| `error_handler` | A handler node receives `NodeError` (`node`, `error`) and `Runtime[Ctx]` (context and `execution_info.node_attempt`); it returns `Command(update, goto)` |

**Conclusion:** the design holds. A `TurnSaver` that extends `InMemorySaver` with a bundle export and import is enough; the serialized payloads are already `(type, bytes)`, so the bundle needs zstd and base64 only. P2-04 builds the production `TurnSaver` from this and runs the conformance suite in CI. The fallback (a run registry for the handler) is not needed.
