# SP-3: `astream_events(version="v3")` from graphs invoked inside nodes

Script: `spikes/test_sp03_events_v3.py` (3 checks, all pass). The v3 API is marked experimental and emits `LangChainBetaWarning`.

| Question | Result |
|---|---|
| Tokens of an agent graph invoked in a root node | `messages` events: `message-start`, `content-block-start`, `content-block-delta` (`text-delta`, `tool-call-delta`), `content-block-finish`, `message-finish` with usage |
| Tool events | Only with `transformers=[ToolCallTransformer]`: `tools` events `tool-started` (name, input) and `tool-finished` (the `ToolMessage`) |
| Custom events (`get_stream_writer`) | Only with `transformers=[CustomTransformer]`: from a tool inside the agent and from a child and grandchild graph |
| Namespaces (DR-11) | `["agent_1:<task id>"]` for the agent graph; `["sub_1:<task id>", "nested:<task id>"]` for a graph invoked inside a child graph's node; the agent's internal `model` and `tools` nodes add no segment |
| Lifecycle | `lifecycle` events `started` / `completed` per nested graph, with its namespace |
| Ordering | `seq` is strictly increasing across all events |
| `context`, `durability`, `control` | Accepted. A grandchild graph sees the root run's context through `get_runtime()`. |
| Message metadata | `langgraph_node`, `langgraph_step`, `langgraph_path`, `langgraph_checkpoint_ns`, `ls_model_name`, `run_id`, `thread_id` |
| Interrupt inside a child graph | `await run.interrupted()` is true; `await run.interrupts()` returns the `Interrupt` with its `response_schema` field |

**Conclusion:** the design holds. One condition is missing from it: the SSE mapper must pass `CustomTransformer` and `ToolCallTransformer` (both public exports) to every v3 call. Because v3 is experimental, P2-01 keeps the mapping behind `engine/streaming/` and pins LangGraph to one minor (already `~=1.2.17`). The v2 fallback is not needed.
